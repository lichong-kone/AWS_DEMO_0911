# User Personas — 蛙游记 Froggy Trails (v1)

覆盖 PRD 定义的 5 类用户。每个画像用于映射后续用户故事(见 stories.md)。

---

## P1 — 碎片放松者(上班族 / 学生)
- **代号**:P1
- **一句话**:在工作学习间隙想要几秒钟的放松,不想被"操作"绑住。
- **动机**:低压力的情绪调节;打开看一眼有没有新东西。
- **典型场景**:午休、通勤、课间。单次停留 30 秒~2 分钟。
- **痛点**:讨厌高频签到、收菜压力、复杂操作、错过就损失。
- **目标**:一两下点击就能"喂一口、放它走",随时回来有惊喜。
- **对产品的期待**:极简操作、不惩罚离线、氛围治愈。

## P2 — 想旅行但没时间者
- **代号**:P2
- **一句话**:向往远方,但现实走不开,想要"替我看看世界"的想象。
- **动机**:通过真实地点/城市获得"远方感"与陪伴。
- **典型场景**:睡前、加班后,想看看小家伙今天去了哪。
- **痛点**:纯数值游戏没有情感投射;假地点没有代入感。
- **目标**:看到真实世界地点 + 有故事感的明信片与日记。
- **对产品的期待**:地点真实可信、文案有温度、旅行不可完全控制带来的惊喜。

## P3 — Cozy / 放置游戏玩家
- **代号**:P3
- **一句话**:喜欢慢节奏、等待型、陪伴型体验的玩家。
- **动机**:享受"准备→等待→反馈"的节律与养成陪伴感。
- **典型场景**:碎片时间多次短开;长线持续数周。
- **痛点**:强逼氪金/广告/体力会破坏放松感。
- **目标**:稳定的循环节律 + 逐渐成长的可见进度(但不是硬核数值)。
- **对产品的期待**:等待被尊重为玩法、动效细腻、无强制变现。

## P4 — 收藏型用户
- **代号**:P4
- **一句话**:为"集齐"而持续——地点、明信片、邮票、纪念品。
- **动机**:完成度、稀有度、点亮地图与相册的满足感。
- **典型场景**:长期使用,会为特定稀有内容反复出行。
- **痛点**:收藏无意义或无法回顾;稀有度用抽卡话术会反感。
- **目标**:清晰的收藏进度、可回顾的手帐/地图、有辨识度的稀有表现。
- **对产品的期待**:地图迷雾点亮、相册跨页手帐、纪念品(含"无意义但有情绪"的物件)。

## P5 — 分享型用户
- **代号**:P5
- **一句话**:收到好看的内容就想分享出去。
- **动机**:表达与社交传播,但不想经营复杂社交关系。
- **典型场景**:收到稀有明信片时,生成一张好看的分享卡发出去。
- **痛点**:分享图丑、信息过载、需要复杂社交系统。
- **目标**:一键生成"我的小家伙今天去了 X"的漂亮分享卡。
- **对产品的期待**:分享卡只保留画面/地名/日期/一句话/品牌角标,足够美观。
