# Integration / Manual Loop Test — v1

v1 为纯前端应用,模块间集成主要通过 gameStore 编排。核心闭环手动验收步骤:

## 核心闭环走查(在浏览器)
1. **首访/选角色**:打开应用 → 从蛙/獭/刺猬选一只 → 命名 → 点开始。预期:进入小屋,收到新手道具(☘20 + 面包 + 水壶),弹出"关于存档"诚实提示。
2. **准备行囊**:点"准备行囊" → 放入食物(面包)与装备 → 看到"隐约的倾向"提示(不显示目的地)→ 确认并出发。预期:小蛙进入旅行中,首旅 30–90 秒。
3. **等待与结算**:停留或切走再回来。预期:约到达时间后,自动结算并以卡片滑入方式弹出明信片。
4. **归来收获**:旅行结束 → 小蛙回家。预期:相册出现明信片 + 纪念品,地图对应地点点亮。
5. **收集回顾**:地图页显示"已发现 x/10"与点亮点;相册页手帐式展示明信片+日记+纪念品。
6. **分享**:相册中点"生成分享卡" → 下载 PNG。
7. **商店/经济**:庭院累积三叶草 → 收取 → 商店用三叶草购买(不足时被拒且不扣款,无真实支付入口)。
8. **双语/无障碍**:我的页切换 中/英;开启"减少动效"后动效停止。
9. **持久化**:刷新页面 → 状态(含进行中的旅行时间线)完整恢复。

## 自动化冒烟(已执行)
