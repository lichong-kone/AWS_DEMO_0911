## 交付物
- 可运行的 Next.js 14(App Router)应用,位于工作区根目录。
- 领域引擎(纯函数 + 注入 seeded RNG)+ 12 项单测。
- 10 个中英双语种子地点、道具、纪念品、日记。
- 完整核心闭环:选角色/命名 → 新手道具 → 准备行囊(模糊提示)→ 出发 → 客户端惰性可复现结算 → 明信片滑入 → 归来 → 纪念品/地点知识 → 地图点亮 → 相册手帐 → 分享卡;软货币商店;庭院经济;IndexedDB 本地存档;i18n;减少动效/无障碍;丢档诚实提示。

## 已知 v1 边界(设计内)
- 无后端/账号/云同步(清浏览器数据会丢档,应用内已诚实提示)。
- 无实时地图 tile / 天气 / 维基数据(用内置种子数据 + 静态点亮)。
- 明信片画面用原创 SVG/emoji 占位素材(可后替为插画),非运行时 AI 生成。
- 无 PWA 推送、无真实支付。
- 时长为便于体验的压缩配置(秒/分级),可用 `lib/engine/config.ts` 常量放大到 PRD 的分/时/天。
