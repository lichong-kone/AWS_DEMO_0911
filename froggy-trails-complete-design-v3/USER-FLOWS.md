# 关键用户流程

## Flow A：首次使用到第一次旅行
`Welcome → Character Select → Home → Backpack → Confirm → Traveling → First Mail → Return Summary → Album/Map`

关键规则：首趟旅行控制在 3–8 分钟，让用户第一次 session 内看到完整闭环；从第二趟起恢复真实等待。

## Flow B：日常 30 秒回访
`Home → harvest clover → check status/mail → leave`

日常回访不能逼用户完成任务；如果青蛙仍在旅途中，允许用户只看一眼就离开。

## Flow C：收到明信片
`Notification/Mailbox → Inbox → Postcard Detail → Save → Album`

旅途中可以先隐藏精确地点；回家后自动补全地点并把地图 Pin 点亮。

## Flow D：旅行归来
`Return Notification → Trip Summary → Destination Reveal → New Souvenirs → Map Unlock → Home`

结果释放顺序：先角色回家，再地点揭晓，再明信片，再纪念品，再地图变化。

## Flow E：长期收藏
`Album/Map → Destination Detail → Postcard Variant / Souvenir → Collection`

重复到访不是失败：季节、天气、同行者、角色行为可以产生新变体。

## Flow F：库存不足
`Backpack → missing item → Shop → Buy → Return to Backpack`

返回行囊时保留用户之前已经选好的槽位。
